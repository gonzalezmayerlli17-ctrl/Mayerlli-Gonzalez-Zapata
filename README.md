## 🚀 Proyectos académicos destacados

### 1. Sistema de Control de Acceso RFID

**Tecnologías:** Arduino Uno, lector RFID RC522, PHP, MySQL, XAMPP, HTML y CSS.

Proyecto académico orientado a la identificación y el control de acceso mediante tarjetas RFID, con una aplicación web para gestionar la información.

**Actividades relacionadas:**
- Diseño de una base de datos para registrar la información.
- Organización de los archivos y componentes de una aplicación web.
- Exploración de formularios de registro e inicio de sesión.
- Integración conceptual entre el lector RFID, el software y la base de datos.
- Identificación y corrección de errores durante el desarrollo.

### 2. Sistema de gestión de cine

**Tecnologías:** PostgreSQL, SQL y pgAdmin.

Diseño de una base de datos para administrar películas, salas, funciones, espectadores y boletos.

**Actividades relacionadas:**
- Creación de tablas y definición de relaciones.
- Consultas SQL con filtros, agrupaciones y funciones de agregación.
- Consultas con múltiples tablas mediante `JOIN`.
- Uso de subconsultas.
- Elaboración de funciones y procedimientos para operaciones como la venta de boletos.
- Validación de la disponibilidad de asientos.

### 3. Sistema de alquiler de vehículos

**Tecnologías:** MySQL y MongoDB.

Ejercicio de modelado y organización de información para administrar clientes, vehículos, contratos, pagos y multas.

**Actividades relacionadas:**
- Identificación de entidades y relaciones.
- Diseño del modelo relacional.
- Organización de colecciones y documentos.
- Registro de contratos, pagos y devoluciones.
- Representación de información de alquiler mediante estructuras de datos.

### 4. Ejercicios de programación orientada a objetos

**Tecnologías:** Python y Java.

Actividades prácticas centradas en la lógica de programación y la organización del código.

**Temas trabajados:**
- Clases, objetos, atributos y métodos.
- Condicionales y operadores lógicos.
- Validación de información.
- Manejo de productos e inventarios.
- Estados de préstamos de libros.
- Resolución de problemas mediante instrucciones paso a paso.
